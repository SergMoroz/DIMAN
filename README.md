# ДИМАН

Автоматический контроль качества деталей для OnePlus 13.  
Фирма «Полёт».

Исходный код приложения **не изменялся**.  
В репозитории лежит оригинальный файл и готовый APK для установки на телефон.

Репозиторий: [github.com/SergMoroz/DIMAN](https://github.com/SergMoroz/DIMAN)

---

## Скачать и установить APK

Готовый файл:

- в релизе: [Releases](https://github.com/SergMoroz/DIMAN/releases)
- в репозитории: [`apk/DIMAN-1.0.0.apk`](apk/DIMAN-1.0.0.apk)

### Как поставить на OnePlus 13

1. Скачайте `DIMAN-1.0.0.apk` на телефон.
2. Откройте файл.
3. Если система спросит разрешение на установку из неизвестного источника — разрешите для браузера или «Файлы».
4. Нажмите **Установить**.
5. При первом запуске разрешите **камеру** и доступ к **снимкам**.

Приложение называется **ДИМАН**, иконка тёмная с бирюзовым знаком.

---

## Что внутри APK

Это тот же интерфейс ДИМАН, открытый как обычное Android-приложение:

- снимок камерой или из галереи;
- режим АВТО / РУЧНОЙ;
- рамки дефектов, вердикт, FMEA.

Код экспертизы не переписывался. Обёртка только показывает исходное приложение на весь экран телефона и даёт доступ к камере.

## Важно знать перед работой в цехе

В оригинальном коде ключ нейросети пустой:

```js
const apiKey = "";
```

Поэтому **разбор фото сейчас не запустится**, пока ключ не появится на стороне сервера.  
Ключ специально **не вписывался** в программу: вы запретили менять код.

Также это визуальный помощник, а не поверенный измерительный прибор.  
Список необходимых доработок — в файле [ИСПРАВЛЕНИЯ.md](ИСПРАВЛЕНИЯ.md).

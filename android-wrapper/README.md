# Обёртка Android для ДИМАН

Это **не правки исходника ДИМАН**.  
Исходный интерфейс упакован как есть и открывается на весь экран телефона.

Исходник лежит в `../source/` и совпадает с оригиналом по SHA-256.

## Что делает обёртка

- открывает приложение в WebView;
- даёт доступ к камере и галерее;
- вибрация и интернет — как в исходнике.

## Сборка APK

Нужны JDK 17 и Android SDK (platform 34, build-tools 34.0.0).

```bash
echo "sdk.dir=/путь/к/android-sdk" > local.properties
gradle assembleRelease
```

Готовый файл появится в `app/build/outputs/apk/release/`.

Ключ подписи: `app/diman.keystore` (alias `diman`).  
Он нужен только чтобы обновления ставились поверх этой версии.
